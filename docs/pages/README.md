## Getting Started

1. **Login** - Access the dashboard at `http://localhost:5001` (default: admin/admin123)
2. **Overview** - Start with the Overview page for system health status
3. **Explore** - Navigate through pages using the sidebar

## Technical Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Backend**: Python FastAPI
- **AI/ML**: TensorFlow, Gemini AI, Groq
- **Monitoring**: Fluent Bit, Prometheus metrics
- **Containers**: Docker, Docker Compose
